# Instamart Grocery Stores Sales Analysis

## 📊 Project Overview

This project analyzes Instamart grocery store data using Microsoft
Power BI to understand sales performance, store characteristics,
product categories, order trends, and customer ratings.

The project includes data analysis, data processing, DAX calculations,
and an interactive Power BI dashboard.

## 🎯 Project Objective

The objective of this project is to analyze grocery store sales data
and identify useful business insights related to:

- Store performance
- Product categories
- City type
- Shop size
- Shop type
- Sales and order trends
- Customer ratings

## 🛠️ Tools & Technologies

- Microsoft Excel
- Microsoft Power BI
- Data Cleaning
- Data Modelling
- DAX
- Data Visualization
